# 万科装修中古风协作网站 V6.1

从原 V6 手机预览文件恢复页面、43 项基础采购数据、14 项候选建议及 7 张原图，保留原预算和选型。网站为公开家庭讨论方案，报价、型号、尺寸与工期仍需核实。

家人在卡片填写建议后，登录 GitHub 并确认创建 Issue。负责人检查全部 JSON 修改内容，添加「采纳更新」标签后触发校验、更新与发布。只有仓库具备 write、maintain 或 admin 权限的人可审核。新增建议本身不会更改正式数据；仅本机试改不会共享。

自动处理检查字段白名单、类型、金额、月份、链接与修改前原值，拒绝冲突、修改审核后文本及重复采纳。审核失败在 Actions 留有记录；处理前应检查 Issue 的全部 JSON 数据。不要在公开网页或 Issue 填写地址、联系方式、凭据及其他隐私。

正式数据为 renovation.json。页面每分钟及回到前台时刷新，也可手动刷新。聊天中讨论不会自动写入仓库，需明确提交并发布。图片为原聊天所给参考素材，未额外获取使用授权，不为其设置开源授权。

本地验证：`node review-change.test.cjs`。生成网站：`node build-site.cjs`。发布目录只含网页、数据和图片；自动审核脚本不进入 Pages 成品。
